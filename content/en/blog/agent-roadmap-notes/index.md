When I started working on agents for geospatial AI, most of my time went into finding out what to read next. Blog posts, courses and papers were plentiful, but the order in which they made sense was not obvious, and many resources were only available in one language.

The [LLM Agent Roadmap](https://ankky-zhao.github.io/llm-agent-roadmap/) is my attempt to write that order down. It groups the field into stages, links each stage to resources I found useful, and keeps a timeline of papers that shifted the direction of the field. Keeping the content in plain JSON makes it easy for others to correct or extend it, and a monthly update keeps it from going stale.

It is a personal map rather than a complete survey, so suggestions are very welcome on [GitHub](https://github.com/Ankky-Zhao/llm-agent-roadmap).
