The roadmap organises the field into stages, from foundations and tool use to retrieval, multi-agent systems, agentic reinforcement learning and safety. Each module links to curated tutorials, courses and code, and a timeline traces key papers from 2020 onwards.

Content lives in JSON files separate from the page, so others can propose resources through pull requests. The site is refreshed on a monthly cycle.
